## Architecture Optimizations (Completed ✅)

### 1. Bundle AST Dependencies (Size & Speed)
- [x] Configure `tsup.config.ts` to bundle `unified`, `remark`, and `rehype` ecosystems.
- [x] Externalize only massive binaries/WASM (e.g., `playwright-core`, `shiki`).
- **Impact:** Eliminates thousands of `node_modules` files and saves ~150-300ms in file-system I/O during startup.

### 2. Mermaid.js Asset Decoupling (Size)
- [x] Move `mermaid` from `dependencies` to `devDependencies`.
- [x] Inject `mermaid.min.js` directly via a local asset or CDN fallback rather than requiring it in the main bundle.
- **Impact:** Removes ~4MB from the core CLI bundle.

### 3. Playwright Parallelization (Speed)
- [x] Refactor `src/commands/convert.ts` to execute Playwright `page.pdf()` calls concurrently using `Promise.all` with a controlled worker limit (`os.cpus().length`).
- **Impact:** Drops batch processing time from O(N) to O(N/Cores).

### 4. Unified Cache Implementation (Speed)
- [x] Implement SHA-256 caching for unchanged Markdown files in `src/core/cache.ts`.
- [x] Store cache index locally to skip Playwright invocation entirely on cache hits.
- **Impact:** Drops second-run conversion times to < 5ms per file.

### 5. Singleton Shiki Instances (Memory & Speed)
- [x] Refactor `src/parser/index.ts` to use a singleton Shiki highlighter.
- [x] Load themes exactly once instead of per-file.
- **Impact:** Prevents RAM bloat and drastically speeds up syntax highlighting across large batch runs.
